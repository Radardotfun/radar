Install

Microsoft Edge

Get it from the Edge store
  1. Click Get, then Add extension.
  2. Open x.com. The radar shows under every post.
  3. Updates are automatic.

Chrome · Brave

Download .zip
  1. Unzip the download.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the unzipped folder.
  5. Open x.com. The radar shows under every post.

Android

Quetta Lemur
  1. Install Quetta or Lemur from the Play Store. Chrome on phones can't run extensions. These can.
  2. In that browser, open tryradar.fun and tap Get it from the Edge store, then Get.
  3. Open x.com in that browser (not the X app) and tap the radar under any post.

Store button not working? Download the .crx and import it from the browser's Extensions menu.

iPhone · Safari

Get the free Userscripts app
  1. Install Userscripts from the App Store and open it once.
  2. In Settings, go to Apps, Safari, Extensions, Userscripts. Turn it on and allow All Websites.
  3. In Safari, open tryradar.fun/radar.user.js, tap the page menu at the left of the address bar, then Userscripts, then Install.
  4. Open x.com in Safari and tap the radar under any post.

Other iPhone browsers: Teak or Gear can install Radar from the Edge store.

Any browser · script

Tampermonkey Violentmonkey
  1. Add Tampermonkey or Violentmonkey to your browser. Both are free and work in Chrome, Brave, Opera, Firefox and Firefox for Android.
  2. In Chrome, Brave or Opera, open the manager's Details page in chrome://extensions and turn on Allow User Scripts.
  3. Open tryradar.fun/radar.user.js and click Install.
  4. Open x.com. The radar shows under every post. Updates install by themselves.
